# The Butler Brothers — рабочая сборка сайта

Текущая структура:

- `index.html` — главная страница «О нас»;
- `golden-ratio.html` — лендинг игры Golden Ratio, построенный на концепте №9;
- `authors.html` — страница авторов, построенная на концепте №8;
- `join.html` — страница «Присоединиться»: она собирает текст заявки в браузере и передаёт его пользователю для отправки в сообщения VK;
- `blog.html` — архив заметок: первые три записи о визуальном направлении Golden Ratio и фирменном знаке ARI;
- `3d-models.html` — локальный 3D-просмотрщик для `.glb` и `.gltf`: загрузка с устройства, по прямой ссылке или перетаскиванием;
- `js/viewer-*.js` — независимые модули просмотрщика: загрузка моделей, сцена и камера, интерфейс;
- `js/vendor/` — локальная копия Three.js r180 и его модулей (MIT, см. `js/vendor/THREE-LICENSE`);
- `assets/` — временные визуальные материалы;
- `ASSET-CREDITS.md` — источники временных материалов.

Для локального просмотра откройте `index.html` через локальный сервер. На публичном хостинге точкой входа должен быть `index.html`.

Страница `join.html` не хранит и не отправляет данные анкеты автоматически. Для подключения собственной Google Формы или серверной формы достаточно заменить финальный канал связи на нужный адрес и настроить приём заявок.
